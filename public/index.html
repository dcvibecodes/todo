Sorting

Saving sets the default sorting for Reminders, Notes and Docs. Date added and Name apply to all three; Due date applies to Reminders only, and Notes/Docs fall back to Date added. Today, Scheduled and Completed keep their fixed defaults. Each folder can still choose its own sorting afterwards; sorting syncs across your devices.

Uploads

On by default. Images and PDFs are stored as smaller optimized copies (only the optimized copy is kept), and downloads return those optimized bytes. HEIC/HEIF photos are converted to JPG for compatibility. Turn this off for signed, medical, archival or metadata-sensitive files. Text files are always compressed losslessly and download as the original bytes.

API tokens

Tokens let your other agents work with items — no browser needed. Access is set per tenant below. Read + write covers adding and editing; delete is a separate destructive permission for Notes and Docs. Reminders tokens cannot delete. Tokens still cannot manage folders, settings or the password.

curl examples 
export TOKEN=YOUR_TOKEN
export HOST=https://your-domain.example

# lists
curl -H "Authorization: Bearer $TOKEN" $HOST/api/lists

# add an item (idempotent with a client key)
curl -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: friday-001" \
  -d '{"title":"Call mom","list":"Reminders","due_at":"2026-11-01T18:00:00","has_time":true}' \
  $HOST/api/reminders

# read it back
curl -H "Authorization: Bearer $TOKEN" "$HOST/api/reminders?q=Call%20mom"

# complete it (advances recurring series)
curl -X PATCH -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"completed":true}' \
  $HOST/api/reminders/123
